⚙️ AI Connection (Web & App)

On GitHub Pages or an installed phone app, Google requires your own free Gemini API key (saved only on this device, never uploaded to GitHub). Or you can use the Built-in Coach anytime with no key required!
Khi chạy trên GitHub Pages hoặc App điện thoại, bạn có thể dán Gemini API Key miễn phí (lưu riêng trên máy bạn) hoặc dùng ngay chế độ Built-in Coach không cần key.

📲 Cài đặt English Master như App

🤖 Trên Android (Chrome / Edge):
Bấm nút ⋮ ở góc trên bên phải trình duyệt → chọn Cài đặt ứng dụng (hoặc Thêm vào màn hình chính).
🍎 Trên iPhone / iPad (Safari):
Bấm biểu tượng Chia sẻ (⬆️) ở thanh dưới cùng → kéo xuống chọn Thêm vào MH chính (Add to Home Screen) → bấm Thêm.
Sau khi cài, ứng dụng sẽ mở toàn màn hình không thanh địa chỉ và dùng được kho từ vựng ngay cả khi ngoại tuyến.
